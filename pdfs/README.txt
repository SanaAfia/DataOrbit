Place public module PDFs in the matching folder:

  pdfs/module1/
  pdfs/module2/
  pdfs/module3/
  pdfs/module4/
  pdfs/module5/

Then add each PDF to the corresponding list in the repository-root pdfs.json.
Example:
  {"title":"Lecture notes","path":"pdfs/module1/lecture-notes.pdf"}

Commit and push the PDF and pdfs.json to publish them with GitHub Pages.
Files in these folders are publicly accessible to visitors of the site.
