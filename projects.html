About the Project

DataOrbit is a student-focused digital library for learning data science. It brings together course modules, PDF reading, curated learning resources, coding practice, and a personal project portfolio in one responsive website.

Module PDFs are stored by the local DataOrbit server. Projects, folders, selected theme, and saved lab code are stored in this browser's local storage, so they remain available in this browser profile rather than syncing to other devices.
